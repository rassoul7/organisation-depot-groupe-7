# Groupe 7 — Livrables A1

Le projet porte sur les mauvais usages des modes AES dans les applications Android financières.

## Reproduction

Depuis la racine du dépôt :

```bash
bash code/reproduire.sh
```

Le script régénère le banc d'essai, l'analyse du pilote et l'analyse du témoin vulnérable.

Le pilote est limité à 12 APK financières open source issues de F-Droid. Il ne constitue pas un corpus représentatif des applications commerciales de l'UEMOA.

## Organisation

- `animation/` : source des diapositives ;
- `article/` : article et bibliographie ;
- `code/` : expériences et détecteur ;
- `donnees/` : corpus et APK du pilote ;
- `resultats/` : résultats vérifiés ;
- `discussion/` : questions de discutant ;
- `synthese/` : synthèse de rapporteur ;
- `quiz/` : trois QCM avec réponses.

Les commits, tags et push sont réalisés par chaque membre sous son propre compte GitHub.
