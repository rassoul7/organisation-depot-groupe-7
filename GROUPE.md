# Groupe 7 — Projet A1

- **Membres :** Mouhamadou Rassoul NAME, Ousmane DIALLO, Ndèye Penda NIANG
- **Sujet :** Modes AES dans les applications de paiement mobile
- **Question de recherche :** comment construire et valider un protocole reproductible de mesure des erreurs de chiffrement dans des applications Android financières, avant son application à un corpus commercial de l'UEMOA ?
- **Séance d'animation :** S3
- **Groupe discuté :** groupe 3 — A9, consensus BFT
- **Groupe rapporté :** groupe 4 — A11, outils d'analyse Solidity

Le pilote présenté dans l'article porte sur 12 APK financières open source issues de F-Droid. Il ne permet pas d'estimer la prévalence dans les applications commerciales de paiement ou de mobile money de l'UEMOA ; cette extension est un travail futur.
